# R2-P3 多实例本机记录

日期：2026-09-23–24。范围：R13 实例生命周期、R14 限定授权与撤销、R15 收件箱/委派/共享资源、
R16 等待/唤醒/公平调度，含模型可见协作面（spawn/delegate/send/wait）与多实例 supervisor。
结果：阶段退出条件成立——任意获准通信图可执行（spawn→delegate→结清→唤醒→目标完成端到端）、
单写上下文（每实例一个相位机驱动，共享单写存储 worker）、统一目标预算（A18）。
真实模型验收、MCP/Skills、其余供应商、TUI 接入与性能实验仍属 P4 及以后。

| 模型可见协作面 | `core/src/kernel/types.rs`、`engine/src/v2/driver.rs` | kernel 识别单独 wait 调用为 KernelOutput::Wait（混用忽略+note）；协作 schema 按当前授权注入（wait 恒可用）；协作意图以实例身份经控制命令执行，命令结果为工具回执；原子 spawn_instance 一事务创建实例+派生 delegate 授权+初始任务与窄返回路径，创建不授予任何连接/文件范围（§5.1） |
| 任务结清闭环 | `core/src/v2/control.rs`、`engine/src/v2/driver.rs` | complete_task 同事务关闭承接者完成回合（条件 UPDATE 不动活动相位），队列非空追加续跑 note；新命令 close_completion 幂等关闭空队完成回合；驱动无目标完成路径按存储候选映射 outcome→任务状态结清最旧未结任务；step_ready 空闲判定计入未结承接任务，开回合前自动 start_task 承接最旧 PENDING |
| 多实例 supervisor | `engine/src/v2/supervisor.rs` | 一协调器持锁+bootstrap 后跑发现循环：ACTIVE 实例各起相位机驱动（共享单写存储 worker），spawn 的实例中途加入，TERMINATED 退休驱动，全部终止后退出；用户输入按实例立即唤醒（交互优先于轮询，§7）；公平性来自有界相位步在控制事务处让出调度权 |
| 共享目标预算（A18） | `core/src/v2/control.rs`（begin_request） | 无目标实例的计费目标解析为其承接任务队列的目标（RUNNING 优先、FIFO），worker 的预留/用量/未知费用全部落在共享目标上；预算拒绝经同一闸门作用于每个实例 |

## 验证中发现的真缺陷（已修复并有回归）

| 缺陷 | 影响 | 修复与回归 |
|---|---|---|
| supervisor shutdown 挂起 | 发现循环只认"排空+全终止"退出；handle 排空驱动后对仍 ACTIVE 的实例重新拉起驱动，shutdown 永不返回 | 共享停止标志 + 退出时停掉竞态残留驱动；`shutdown_with_an_active_instance_still_exits` |
| WAITING 实例的消息唤醒缺口（A23） | message 类等待要求信封 APPLIED，而 drain 此前只发生在 step_ready——停放实例永远无法被消息唤醒 | WAITING 轮询分支补 drain_inbox（重放安全），应用信封同事务满足等待；`a_waiting_leader_wakes_when_the_peers_message_is_applied`（先等 leader 进入 WAITING 再发信，确定性走停放路径） |
| 无目标实例的完成回合卡死 | worker finish 后停在 COMPLETION_PENDING，驱动报"without an active goal"错误 | step_completion 无目标路径：结清最旧未结任务/空队 close_completion；`worker_finish_*` 三项 |

## 已知边界（明确留给后续）

- worker 工具能力来自 spawn 时继承的 profile；shell@workspace 等范围授权仍按 §5.1 显式签发，
  多实例下的工具执行证据（含批准跨实例）在 P4 真实任务中补齐。
- 多目标混合队列的计费按"最旧 RUNNING"归属，是确定性近似；单实例同时服务多目标的精确拆分
  尚无需求依据。
- supervisor 发现循环对驱动任务失败采取下一周期重建（状态驱动恢复天然幂等），无退避；
  ponytail：持续崩溃的实例应计入失败并泊车而非循环重建。
- 公平性目前是 tokio 协作式让出 + 输入即时唤醒；无跨实例配额调度，R16 的调度上限在
  P6 性能阶段按测量决定。

# R2-P0 本机探针记录

日期：2026-09-23。结果：隔离原型探针与真 PTY 贯通通过。R2-P0 不调用模型，因此本记录是工程故障与本地开销证据，不是 Agent 能力或生产实现验收。

## 环境与复跑

- Linux，Rust `1.95.0`，Cargo `1.95.0`；SQLite `3.53.2`（rusqlite bundled）。
- 命令：

```bash
cargo build --offline --locked --manifest-path engine/Cargo.toml --example rebuild_p0
cargo build --offline --locked --manifest-path tui/Cargo.toml --example rebuild_p0
engine/target/debug/examples/rebuild_p0 suite review/tmp/r2-p0-new
python3 tui/scripts/pty_rebuild_p0.py
```

- 原始结构化报告：`review/tmp/r2-p0-final/report.json`。重跑时需指定此前不存在的新目录。

## 故障边界

所有探针断言通过：

- 在事务提交前 SIGKILL 后没有部分输入；提交后 SIGKILL 后完整恢复。两种恢复均重复应用输入，结果固定为 1 个上下文条目、1 个事件、revision 1；同 ID 不接受不同载荷。
- WAL 数据库页数上限触发 `SQLITE_FULL`，没有填满宿主磁盘。
- 制品发布进程 SIGKILL 后 STAGING 不被 GC 删除；活动引用可读。GC 认领对象后拒绝迟到引用，重启后完成删除；未导入 job 制品受保护。
- CANCEL 先于 GO、runner 重启和重复 GO 后，副作用启动次数为 0。重复 GO 的正常任务只产生一个副作用；回执重复导入只生成一个事件。
- runner 已接受 GO、记录启动前崩溃时恢复为 `OUTCOME_UNKNOWN`，不会猜测或重放。runner 在执行期间崩溃同样不盲目重做；daemon 崩溃后独立 runner 继续完成同一 job，副作用次数为 1。
- SQLite 取消写失败后仍经核验的进程组通道停止命令，实测约 12 ms；回执明确表示取消未保存。受控 deadline 独立停止超时命令。
- daemon 文件锁拒绝第二协调者；子 runner 不继承锁。重复 command ID 返回同一回执，TUI 退出期间任务继续。

## 本地开销与 I/O 对照

1,000,000 个合成单位、5,000,000 字节（不经过 tokenizer），120 次短事务：追加/应用 p50 1,384 µs、p95 1,615 µs，数据库增长 16,384 字节；请求 JSON 构造 101,302 µs，5,000,043 字节；重开及制品摘要核验 76,374 µs。报告时 RSS 25,600 KiB，峰值 RSS 29,484 KiB。此单次本机探针只显示每步未复制 5 MB 历史，不代表稳定 benchmark。

本地停滞 HTTP body 下，控制 round-trip 各测 12 次：async 的 p50/p95 为 8/19 µs（1/4/16 活跃请求分别为 8/64、8/12、8/19 µs），取消等待工作者分别约 0.03/0.09/0.23 ms；bounded blocking 的 p50/p95 分别为 8/10、8/47、6/12 µs，取消等待约 354/358/358 ms（等待显式读超时及线程退出）。此结果支持 P0 选择 async I/O 的可取消性假设，不能证明端到端吞吐更高。线程、RSS、CPU 同在 JSON 报告中。

PTY 脚本启动真实 daemon 与 TUI，检查同一 task ID 的断开存活、重连显示、暂停计数冻结、恢复继续和取消。初次检查因标题字节断言假设终端会连续输出标题而失败；按 ratatui 实际光标定位输出调整断言后完整复跑通过。

## 回归门禁

- `make check` 通过：三个 crate 的 rustfmt、严格 Clippy、全部离线锁定测试和仓库卫生检查均成功；真实模型用例仍按原约定 ignored。
- `make pty` 通过：正式 TUI 的启动/输入/退出、面板点击、工作区审查与 `/model` 添加/选择/持久化检查均成功。
- 独立 `python3 tui/scripts/pty_rebuild_p0.py` 通过，覆盖本原型的真实 PTY 断连与控制流程。

## 限制

该原型和报告只关闭 R2-P0 的探针工作。最小演示 daemon 不包含生产 kernel/实例模型；合成上下文不是 DeepSeek 的 1M tokenizer 输入；没有进行系统断电实验、外部真实服务验收或 Terminal-Bench 重跑。P1–P7 及 A01–A36 仍未完成。详细边界见 [R2-P0 执行合约](../docs/R2-P0-CONTRACTS.zh-CN.md)。
